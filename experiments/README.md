# Experiments

Prototype scripts from the first Suno reconstruction study (*All That Time Saved*,
November 2026). They were rescued from an ignored `target/qa` directory so they
survive `mvn clean`. They are reference material, not supported tools.

The source audio, MIDI, renders and evidence they read and write are private and
are kept outside this public repository. Promote any idea worth keeping into the
`headless` pipeline with tests and benchmark coverage.
